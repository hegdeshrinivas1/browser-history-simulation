# Browser History Simulation

A simple Java console-based mini project that simulates browser history using `LinkedList` and `ListIterator`.

## Features

* Visit a new page
* Go back
* Go forward
* View current page
* View browser history
* Handles invalid input

## Concepts Used

* Java
* LinkedList
* ListIterator
* OOP
* User Input & Validation

## Purpose

Built as a mini project to understand Java Collections, `ListIterator`, and basic OOP concepts.
